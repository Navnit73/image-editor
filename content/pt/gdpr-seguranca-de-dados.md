# Conformidade LGPD e Segurança de Dados

No **PhotoResizer AI**, a segurança dos dados e a conformidade regulatória com a **Lei Geral de Proteção de Dados (LGPD)** e o **GDPR** são garantidas por arquitetura.

---

### 1. Proteção de Dados por Design (LGPD Art. 46)
A LGPD exige que os agentes de tratamento adotem medidas de segurança e engenharia capazes de proteger os dados pessoais.

O PhotoResizer AI atende a essa exigência por meio de uma garantia técnica:
- **Sem Ingestão Externa**: Suas imagens são carregadas via APIs JavaScript diretamente na memória do seu navegador.
- **Sem Envio de Dados**: Nenhum dado de imagem ou arquivo é transmitido pela internet.
- **Limpeza Automática**: Ao fechar a aba do navegador, a memória temporária é limpa pelo sistema operacional.

---

### 2. Proteção de Dados Biométricos
Ao utilizar o **Gerador de Fotos para Passaporte** para criar fotos de RG, CNH ou Visto, o PhotoResizer AI **nunca armazena ou analisa dados biométricos**. As guias de alinhamento facial são sobreposições vetoriais calculadas no seu próprio navegador.

---

### 3. Contato do Encarregado de Dados
Para dúvidas regulatórias sobre a LGPD, entre em contato com nosso Encarregado de Proteção de Dados pelo e-mail **privacy@photoresizerai.com**.
